# Grecs du Roi — a free 21st-century revival of Estienne's 1550 Greek

An open font + reading-site project recreating the *Grecs du Roi* — the
Greek minuscule cut by Robert Estienne in 1550 (attributed to a
Garamond-derived punchcutter), digitised here as live OpenType so a
scan-faithful page of Estienne's folio 161 (John 1) can be read with real
GSUB ligature fusion, and toggled to a modern polytonic face on the
*identical Unicode text*.

- Live server: greek.craven.fr (HTTPS enabled 2026-11-10 via DNS A record + `deploy/enable-tls.sh`)

## What ships

| Path | What |
|---|---|
| `src/index.html` | Ligature specimen — every item on Wikipedia's *Greek ligatures* list, rendered live via GSUB |
| `src/estienne-john1.html` | Estienne 1550 folio-161 recreation (John 1), scan-collated, with **grecs du roi ⇄ modern polytonic (Cardo)** toggle |
| `src/fonts/` | Webfont stack + desktop OTFs; `LICENSES.json` proves every face is OFL |
| `tools/` | Build pipeline + QA gates (see below) |
| `corpus/` | PD polytonic corpora driving coverage measurement (WH 1881, scan-collated Estienne wording) |
| `docs/` | The phase plan and the project's answers |

## The font pipeline

```
GFS Gazis (OFL) ──build_typography.py──▶ GrecsRoi Greek (upright)
                                   └─▶ cursive_masters.py ─▶ slanted masters
                                          └─▶ ligature_engine.py ─▶ 165 fused ligatures (GSUB liga/dlig, grek/DFLT)
```

Rebuild everything:

```
python3 tools/build_typography.py     # fonts + subsets + coverage.json
python3 tools/build_estienne_page.py  # reader page from corpus JSON
python3 tools/license_manifest.py     # regenerate src/fonts/LICENSES.json
```

## QA gates (what CI runs)

| Gate | Proves |
|---|---|
| `tools/fusion-coverage.py` | ≥60% of corpus words carry a real HarfBuzz-verified fusion (currently 97.3%) |
| `tools/qa_cursive.py` | Cursive face QA incl. accented omicron-sigma punch-list items |
| `tools/qa_fusion_toggle.py` | Fusion fires ON and is inert OFF in Chromium+Firefox+WebKit; hero cells contain zero PNGs |
| `tools/qa_reader_toggle.py` | The reader's grecs-du-roi ⇄ Cardo toggle changes *only* the font stack — text is byte-identical NFC, Cardo covers every codepoint on the page, no PUA, no bbox warnings |
| `tools/license_manifest.py --check` | Every shipped glyph is OFL/PD; manifest matches the bytes |

Copy-paste invariant (holds in all modes): selected text pastes as ordinary
NFC polytonic Greek — no PUA anywhere.
